# Dynamic Island module template

A complete, working module for [Dynamic Island for Android](https://github.com/ajitpal/dynamic-island-android):
a tool in the island, a card with buttons, and a tile on the app's Island tab.

**With an AI coding agent:** open this folder (or a repo made from it) in Claude Code, Codex, Copilot or similar
and describe your idea. The agent reads `AGENTS.md` and the
[agent guide](https://github.com/ajitpal/dynamic-island-android/blob/main/docs/modules/AGENT_GUIDE.md) and does the rest, up to opening the listing request.

**By hand:** follow the same guide. Build with `./gradlew assembleDebug` (JDK 17).
